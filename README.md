# Build Asteroids
A Python project built during the Boot.dev course: [Build Asteroids using Python and Pygame \[Full Course\] | Boot.dev](https://www.boot.dev/courses/build-asteroids-python)

This project is a simple implementation of the classic game Asteroids using the Pygame library. It includes features such as player movement, asteroid spawning, collision detection, and scoring.

## Installation

To install and run this project, follow these steps:

1. Ensure UV is installed (e.g. with `pip install uv`)
2. Clone the repository
3. Pin Python to version 3.13 with `uv lock python-version=3.13`
4. Create a virtual environment with `uv venv` and activate it with `source .venv/bin/activate`
5. Install Pygame with `uv add pygame==2.6.1`
6. Activate the virtual environment with `uv activate venv`
7. Run the game with `uv run main.py`

## Controls

* Move the player with the <kbd>&larr;</kbd>, <kbd>&uarr;</kbd>, <kbd>&darr;</kbd>, and <kbd>&rarr;</kbd> keys
* Shoot with right <kbd>^ Ctrl</kbd>
